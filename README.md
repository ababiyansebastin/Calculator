# Calculator
A python calculator used from the Terminal, built step by step in SCCM4910.

## What it will do
add, subtract, multiply and divide two numbers; 
also does batch calculations from the files in data 


## How to run?
Run: 'python3 calculator.py' / 'python3 batch_runner.py' for batch calculations 
Operations: + - * / (two numbers)
input: first number, followed by operations, followed by secondary number 

The program prints 'Result:' followed by answer.

## Acceptance criteria
accurate results given
batch calculations from 'data/' are given according to the 'requirements.md'
